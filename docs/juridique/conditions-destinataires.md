# Ce qu'il faut savoir quand vous recevez un colis Tara

Version 2026-11.1 · Projet à faire valider par un juriste. Texte affiché sur la page de suivi et
accessible depuis le lien des SMS.

Vous recevez un colis envoyé par une boutique ou un particulier avec Tara. Vous n'avez pas besoin
de compte ni d'application.

1. **Suivi** : le lien reçu par SMS ou WhatsApp vous montre où en est la livraison, le nom du
   livreur et l'heure d'arrivée estimée. Ne transférez pas ce lien.
2. **Code de livraison** : vous recevez par SMS un code à 4 chiffres. **Vérifiez d'abord l'état
   du colis**, puis donnez le code au livreur. Ce code prouve que vous avez reçu le colis en bon
   état apparent.
   - **Colis abîmé** : refusez-le. Le livreur le photographie et le ramène ; Tara ouvre une
     réclamation pour l'expéditeur.
   - **Dommage découvert à l'ouverture** : prévenez l'expéditeur ou le service client de Tara
     dans les 7 jours qui suivent la livraison (dimanches et jours fériés non compris), avec
     des photos.
3. **Paiement à la porte** : si l'expéditeur l'a prévu, vous payez au livreur la somme affichée
   sur la page de suivi (prix de l'article et/ou livraison), en espèces ou par Mobile Money.
   Le livreur ne peut pas vous demander plus. Par Mobile Money, la demande arrive sur votre
   téléphone : validez-la avec votre code secret.
4. **Absence** : si vous n'êtes pas joignable, le livreur vous appelle deux fois avant de
   repartir. L'expéditeur décide alors d'une nouvelle tentative ou du retour du colis. Ces
   frais ne vous sont jamais demandés.
5. **Vos données** : votre nom, votre numéro et votre adresse servent uniquement à cette
   livraison. Ils sont masqués 30 jours après la fin de la livraison.
6. **Un problème ?** Contactez le service client de Tara : **[À VALIDER : numéro et horaires]**.
