## Résumé

- **Vraie carte sur les pages web** (suivi du colis et « Mon point ») : rues de Douala avec le style des apps. MapLibre est servi par la page (aucun script d'un autre site) et chargé après elle ; sans WebGL ou sans réseau, la ville dessinée reste.

- **Carte « Votre code de livraison »** : le code n'est jamais affiché, seulement le numéro masqué et l'heure d'envoi. « Je n'ai pas reçu le code » renvoie un nouveau code au numéro enregistré (3 fois au plus, 2 min d'écart, essais ratés du livreur non remis à zéro).
- **API** : `PublicTracking.map` (point de livraison, livreur seulement quand il vient), `PublicTracking.deliveryCode`, `POST /public/tracking/:token/delivery-code` (limitée à 5/min), migration `delivery_code_resends` / `delivery_code_sent_at`.
- Politique de sécurité des pages : tuiles autorisées seulement chez le fournisseur de tuiles, worker de la carte servi par la page.
