## Expéditeur absent : le livreur peut partir après 30 minutes, attente payée

Proposition validée par le fondateur. Quand l'expéditeur ne vient pas remettre le colis, le livreur peut repartir, payé, avec quatre garde-fous contre la fraude et les disputes :

1. **30 minutes après « Je suis arrivé »**, comptées par le serveur (pas l'horloge du téléphone) ;
2. **encore sur place** : 300 m au plus du point d'enlèvement ;
3. **deux appels à l'expéditeur** depuis l'arrivée, passés depuis l'app et joints comme preuve ;
4. **expéditeur prévenu à 25 minutes** : « votre livreur partira dans 5 min ; 700 FCFA si vous ne venez pas » (une fois par envoi).

### Argent

- La course est annulée ; ce qui était payé d'avance revient, puis l'expéditeur paie l'annulation (300 F) et l'attente maximale (400 F) : **700 F**, dont **480 F pour le livreur** et 220 F pour Tara.
- Pris sur le solde Tara puis les ventes (boutique) ; dette sinon. Une seule fois pour un envoi groupé : les autres colis qui attendaient le même livreur sont annulés sans frais.
