# tara_ui

Design Tara partagé par l'app livreur (`apps/rider`) et l'app expéditeur (`apps/client`) :
couleurs et thèmes clair et sombre, typographie, composants (boutons, cartes de verre,
champs, puces), animations liquides, icônes de la maquette, polices embarquées.

Un écran s'écrit avec ces briques ; une nouvelle couleur ou un nouveau composant s'ajoute
ici, jamais dans une seule app. Polices : `packages/tara_ui/Sora` et
`packages/tara_ui/PlusJakartaSans` (déclarées dans ce paquet, embarquées par les apps).
