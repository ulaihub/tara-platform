# Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans Tara, ne l'exposez pas dans une issue, une pull request ou un message public. Signalez-la en privé à l'équipe technique de Ulai Hub, avec les étapes pour la reproduire. Nous accusons réception sous 72 heures et vous tenons informé de la correction.

Le fonctionnement de la sécurité, les procédures et les mesures prévues sont décrits dans [docs/SECURITE.md](docs/SECURITE.md).
